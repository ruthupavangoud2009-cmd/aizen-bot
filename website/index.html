Frequently Asked Questions

Everything you need to know about KYOKA's architecture and setup.

What prefix does KYOKA use?

KYOKA responds to both ?, +, and full Discord slash commands (/). You can also configure a custom prefix per guild via +setprefix <new>.

Does KYOKA auto-join voice channels on restart?

No. KYOKA only joins voice channels when an authorized user explicitly issues a command (such as ?play, ?join, or /play). It never intrudes into voice channels automatically.

How does the Anti-Nuke protection work?

KYOKA intercepts audit log events in sub-second time. If an unauthorized administrator deletes multiple channels, bans members in bulk, or modifies danger roles, their roles are stripped immediately and the server is quarantined.

Can I control music from my phone or web browser?

Yes! By logging into the KYOKA Web Dashboard, you can view the live server queue, pause, skip, seek, and adjust studio volume directly from your web browser.
